# Veenit Ramteke — Resume & Portfolio

A responsive personal resume and portfolio site, styled with an external CSS file.

## Preview locally

Open `index.html` in a browser. The Google Fonts link requires an internet connection; the page and image assets are local.

## Structure

- `index.html` — semantic sections, navigation, project cards, achievements, services, and contact details
- `style.css` — color tokens, typography, responsive layout, cards, and motion
- `assets/images/` — profile and project imagery
