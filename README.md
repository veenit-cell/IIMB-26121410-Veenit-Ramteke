## 🛠 Zero-JavaScript Architecture

Every dynamic interaction on the site is built using **pure declarative CSS3 and native HTML5 elements**:

- **Mobile Navigation Drawer**: Implemented using the native HTML5 `<details>` and `<summary>` disclosure element, eliminating the need for toggle event listeners.
- **Infinite Metric Ticker**: Driven by CSS `@keyframes marquee-scroll` with `animation-play-state: paused` on hover for user accessibility.
- **Smooth Section Anchoring**: Powered by native CSS `html { scroll-behavior: smooth; }` and calibrated `scroll-margin-top` offsets to accommodate the sticky header.
- **Interactive States & Hover Feedback**: Dynamic elevation changes, border illumination, and transform states handled via pure CSS transitions (`ease`, `transform`, `box-shadow`).
- **Telemetry Visualizations**: Handled via clean, lightweight SVG vector illustrations directly embedded in the asset directory.
- **Contact Drafting**: Native HTML `<form action="mailto:..." method="get">` form encoding that opens the user's default email client with pre-filled subject and inquiry body.

## 🚀 Featured Projects

### 1. **DRISHTI — Disaster Intelligence & Geospatial Response Platform**
- **Domain:** Decision Intelligence, Geospatial Analytics, Emergency Coordination
- **Architecture:** React 19, TypeScript, FastAPI, PostgreSQL/PostGIS spatial clustering
- **Capabilities:**
  - Deterministic recommendation engine assessing evidence confidence, operational constraints, and road network disruptions.
  - Real-time incident categorization with GIS clustering and automated unassessed sector detection.
  - Offline-first mutation queuing allowing field personnel to log updates without active internet connectivity.
- **Visual:** Dedicated SVG dashboard (`assets/images/drishti-dashboard.svg`) showcasing triage status, route network maps, and resource telemetry.

### 2. **VASH — Financial Fraud Detection & Threat Intelligence Platform**
- **Domain:** Anomaly Detection, Graph Analytics, Security Auditability
- **Architecture:** Python, Scikit-Learn, NetworkX, FastAPI, PostgreSQL, Cryptographic Chaining
- **Capabilities:**
  - Multi-tiered anomaly detection featuring an Isolation Forest engine paired with SHAP value attributions for explainable investigation alerts.
  - Bipartite graph analysis detecting cyclic fund routing, high-velocity structuring, and synthetic mule rings.
  - Tamper-evident ledger protected by sequential SHA-256 cryptographic hash-chaining.
- **Visual:** Dedicated SVG dashboard (`assets/images/vash-dashboard.svg`) illustrating transaction graph topologies and anomaly scores.

### 3. **Prashikshan — AI-Driven Career Readiness & Academia–Industry Interface**
- **Domain:** Educational Technology, Career Pathway Optimization, Skill Validation
- **Architecture:** Node.js, Express.js, SQLite, Role-Based Access Control (RBAC), JWT Authentication
- **Capabilities:**
  - Dynamic skill-gap matrix mapping student competencies directly against real-time industry requirement taxonomies.
  - Multi-stakeholder architecture unifying students, university administrators, and corporate recruiters under structured evaluation rubrics.
  - Automated progress tracking and curated career development pathways.
- **Visual:** Dedicated SVG dashboard (`assets/images/prashikshan-dashboard.svg`) demonstrating student evaluation matrices and career roadmaps.

### 4. **Electronova Robotics Platform — Data-Driven Innovation**
- **Domain:** Embedded Systems, Autonomous Robotics, Sensor Telemetry
- **Architecture:** Microcontroller firmware, ultrasonic sensor array, optical encoders, tuned PID control
- **Capabilities:**
  - Rapid-prototyped obstacle-avoidance robot delivered during a competitive 24-hour robotics sprint.
  - Real-time sensor fusion with closed-loop PID motor regulation ensuring stable dead reckoning and navigation.
- **Visual:** Dedicated SVG dashboard (`assets/images/electronova-dashboard.svg`) displaying polar radar sweeps and sensor telemetry.

## 💻 Local Development

Because this project is built with zero external dependencies and zero build tools, running it locally requires no package installations (`npm install` is not required):

### Option 1: Direct File Preview
Simply double-click `index.html` or open it directly in any modern web browser (Chrome, Firefox, Safari, Edge):
```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

### Option 2: Lightweight Python HTTP Server
```bash
# Python 3
python -m http.server 8080

# Navigate to: http://localhost:8080
```

### Option 3: Node `http-server` or `npx serve`
```bash
npx serve .
```
